## 3. Critério de cobertura (meta)

Meta: 100% de Cobertura de Decisão. Cada uma das 17 decisões deve ser avaliada como True e como False em pelo menos um caso, totalizando 34 ramos: D1T, D1F, D2T, D2F, ..., D17T, D17F.

Definição de caso de teste: UM item em UMA chamada de UpdateQuality, com entrada (Name, SellIn, Quality) e saída esperada (SellIn, Quality). Não agrupe vários itens na mesma chamada para economizar casos.

Busque o MENOR conjunto de casos que cubra os 34 ramos. Se concluir que algum ramo é inalcançável, prove isso em vez de ignorá-lo.
